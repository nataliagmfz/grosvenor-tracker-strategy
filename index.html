How to update the published dashboard

The deployed page automatically loads data.xlsx from this repo on every page load. To update what your boss sees, just replace that one file — no HTML changes needed.

  1. Export the latest .xlsx from Apaleo.
  2. Rename it to data.xlsx.
  3. In your GitHub repo, open data.xlsx → click "Replace this file" (or drag-drop the new file onto the file page) → commit to main.
  4. Your boss reloads the page → sees the new data within ~60 seconds.

Only you have write access to the repo. Anyone with the public link can view, no one else can edit.
